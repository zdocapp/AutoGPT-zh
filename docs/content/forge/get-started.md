# AutoGPT Forge

## 🛠️ 构建您自己的智能体 🛠️

!!! warning
    如果您尝试使用 AutoGPT，本教程并不适合您！您需要使用[这个教程](../classic/setup/index.md)

Forge 是一个为*您的*智能体应用程序准备的即用型模板。所有样板代码均已处理完毕，让您可以将全部创造力投入到让*您的*智能体与众不同的方面。

---

### 🛠️ **为何选择 AutoGPT Forge？**

- 💤 **无需样板代码！** - 不要让繁琐的任务阻碍您。无需从零开始的烦恼，直接分叉并构建！
- 🧠 **以大脑为中心的开发！** - 提供您所需的所有工具，让您 100% 的时间专注于重要事项 - 打造您 AI 的大脑！
- 🛠️ **工具生态系统！** - 我们与一流工具合作，为您带来最佳体验！

---

### 🚀 **快速开始！**

最佳入门方式是分叉或下载 AutoGPT 仓库，并查看 `classic/forge/agent/forge_agent.py` 中的示例智能体。
这可以作为您自己智能体的起点。
智能体使用提供不同功能的*组件*构建，请参阅[组件介绍](./components/introduction.md)。您可以在 `classic/forge/components/` 中找到内置组件。
