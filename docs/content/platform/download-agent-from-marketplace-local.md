# **如何从 AutoGPT 市场下载并导入智能体（本地托管版）**

## **概述**

本指南说明如何从 AutoGPT 市场下载智能体并将其导入到本地托管的实例中。

## **先决条件**

* 已本地安装 AutoGPT
* 具有本地托管版本的市场访问权限

## **分步流程**

### **1. 访问市场**

* 导航至市场板块
    * 注意：界面将与云托管平台有所不同

### **2. 下载智能体**

1. 浏览并选择所需智能体
2. 点击智能体查看详情
3. 找到并点击"下载智能体"按钮
4. 智能体文件将保存至您的计算机

### **3. 导入智能体**

1. 返回 Monitor 标签页
2. 找到"创建"按钮旁边的下拉菜单
3. 选择"从文件导入"
4. 在文件选择对话框中：
    * 导航至已下载的智能体文件
    * 选择文件
    * 点击"打开"
5. 点击"导入并编辑"

### **4. 验证导入**

* 智能体现在应出现在 Builder 中
* 您可以开始编辑或使用导入的智能体

##  **重要说明**

* 本地托管版本与云托管版本的市场界面存在差异
* 请确保遵循本地托管版本的特有步骤
* 成功导入后，智能体将在 Builder 中可用
