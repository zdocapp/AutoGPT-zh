# **如何在 AutoGPT 中编辑智能体**

## **概述**

本指南介绍如何在 AutoGPT 中访问和编辑现有智能体，无论是您自己创建的还是从市场下载的。

## **编辑智能体的步骤**

### **1. 访问监控选项卡**

* 导航至 AutoGPT 构建器中的监控选项卡
* 您将看到所有智能体的列表，包括：
    * 您创建的智能体
    * 从市场下载的智能体

### **2. 选择智能体**

* 从列表中定位要编辑的智能体
* 点击智能体名称进行选择

### **3. 进入编辑模式**

* 查找所选智能体旁边的铅笔图标
* 点击铅笔图标打开编辑器

### **4. 修改智能体**

* 智能体将加载到编辑器中，包含所有现有组件
* 对智能体的配置进行所需修改

### **5. 保存更改**

* 完成修改后，保存更新后的智能体

## **Note**

* 所有智能体均可编辑，无论是由您创建还是从市场下载
* 更改将保存到您的本地实例
