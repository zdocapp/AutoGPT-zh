## **先决条件**

* 使用 AutoGPT Builder 构建的完整智能体
* 提交前必须保存您的智能体

## **提交步骤**

1. **访问提交表单**
    * 导航至市场
    * 点击"提交智能体"按钮
2. **选择您的智能体**
    * 使用下拉菜单选择您已完成的智能体
3. **填写必填信息**
    * 添加智能体的详细描述
    * 输入作者姓名
    * 添加至少一个关键词以帮助用户找到您的智能体
    * 为您的智能体选择最相关的类别
4. **审阅条款**
    * 阅读并同意市场条款
5. **提交审核**
    * 点击"提交"按钮完成提交

## **提交后流程**

* 您的智能体将进入"待处理"状态
* AutoGPT 团队将审核您的提交
* 审核通过后，您的智能体将作为新列表出现在市场中

## **成功提交的技巧**

* 提供清晰详细的智能体功能描述
* 选择能准确描述智能体功能的相关关键词
* 确保提交前智能体经过充分测试并能按预期工作
* 选择最合适的类别以帮助用户找到您的智能体
