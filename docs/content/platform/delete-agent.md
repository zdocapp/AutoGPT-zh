# **如何在 AutoGPT 中删除智能体**

## **概述**

您的 AutoGPT Monitor 是否变得杂乱无章，或者您创建了一个不再需要的智能体？了解如何快速删除不需要的智能体。

## **删除智能体的步骤**

1. **定位智能体**
    * 在 AutoGPT 构建器中导航至 Monitor（监控）选项卡
    * 从列表中找到您要删除的智能体
2. **选择智能体**
    * 点击您希望删除的智能体
3. **删除智能体**
    * 在界面右侧寻找垃圾桶图标
    * 点击垃圾桶图标
    * 将出现一个确认对话框，询问“您确定要删除此智能体吗？”
    * 点击“是的，删除”以确认

一旦确认，该智能体将立即从您的列表中移除。

**注意**：此操作无法撤销，因此在确认前请确保您确实希望永久删除该智能体。
